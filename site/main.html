제1회 · 2025.11.30with Upstage

AI Agent QA 시나리오

  • AI Agent
  • Multi-turn
  • Tool Calling
02

제2회 · 2026.05.23with CJ올리브네트웍스

그래프 신경망(GNN) 기반
조직적 어뷰징 네트워크 탐지

개별 행동을 넘어 관계 속에 숨은 조직적 어뷰징을 탐지하는 프로젝트입니다. 데이터 분석·GNN 모델링·시각화를 수행하고, 대시보드를 통해 분석 결과를 공유했습니다.

  • Graph Neural Network
  • Data Analysis
  • Visualization
03

제3회 · 2026.10.03OCR · Architecture

OCR 기반 상품 소비기한 정보 추출

  • OCR

  • Domain Application
