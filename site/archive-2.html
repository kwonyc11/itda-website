제2회 · 2026.05.23with CJ올리브네트웍스

그래프 신경망(GNN) 기반
조직적 어뷰징 네트워크 탐지

개별 행동을 넘어 관계 속에 숨은 조직적 어뷰징을 탐지하는 프로젝트입니다. 데이터 분석·GNN 모델링·시각화를 수행하고, 대시보드를 통해 분석 결과를 공유했습니다.

  • Graph Neural Network
  • Data Analysis
  • Visualization

프로젝트 소개

제2회 연합 학술제는 CJ올리브네트웍스와 함께 그래프 신경망(GNN)을 기반으로 조직적 어뷰징 네트워크를 탐지하는 프로젝트를 진행했습니다. 개별 행동뿐 아니라 데이터 사이의 관계를 살펴보며 문제를 분석하는 데 초점을 맞췄습니다.

참가팀은 데이터 분석과 GNN 모델링, 네트워크 시각화를 수행하고, 접근 방식과 결과를 분석보고서 및 발표 자료로 정리했습니다. 본선에서는 발표와 시각화 대시보드 시연을 통해 분석 결과를 공유했습니다.
